# AI Engineering Knowledge Base

Welcome to the AI Engineering Knowledge Base for the Base Project Monorepo. 
This directory (`ai_prompts/`) contains the foundational context, architecture rules, and coding standards required for AI agents (like yourself or other assistants) to contribute effectively to this repository.

## Directory Structure
- `AGENTS.md`: Defines the roles and personas of AI agents working on this project.
- `PROJECT_CONTEXT.md`: Business context, goals, and high-level product information.
- `ARCHITECTURE.md`: Technical architecture, monorepo structure, and technology stack.
- `CODING_RULES.md`: Universal coding standards, linting rules, and best practices.
- `AI_WORKFLOW.md`: Standard operating procedures for AI agents (e.g., how to plan, execute, and review).
- `TASK_TEMPLATE.md`: Template for assigning new tasks to AI agents.
- `REVIEW_TEMPLATE.md`: Template for AI agents to review code.
- Specific domain folders (`backend`, `mobile`, `admin`, `web`, `database`, etc.) contain specialized rules for each domain.

## How to use this directory
Before starting any significant task, AI agents should read the relevant context files in this directory to ensure their output aligns with the project's standards and architecture.
