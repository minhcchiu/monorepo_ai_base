# Base Project Monorepo Architecture

## 1. Overview
This document describes the final architecture of the Monorepo after the migration.
The project utilizes `pnpm` workspaces for dependency management and `TurboRepo` for task orchestration. 

## 2. Architecture Structure
The codebase follows a strict **4 Applications + Shared Packages** model.

### 2.1 Applications (`apps/`)
- **`backend`**: NestJS + Prisma application. Serves REST APIs. Port 3000.
- **`mobile`**: Native Android (Kotlin + Jetpack Compose) application. Managed natively via Gradle (excluded from pnpm workspace).
- **`admin`**: Next.js (App Router) internal dashboard for administrators.
- **`web`**: Next.js (App Router) public-facing web application.

### 2.2 Shared Packages (`packages/`)
- **`config`**: Centralized configurations for TypeScript (`tsconfig.base.json`), ESLint (`eslint.config.mjs`), and Prettier (`prettier.config.js`). All apps inherit from these bases.
- **`ui`**: Shared React components used by `admin` and `web`.
- **`shared-ts`**: Shared TypeScript logic, constants, utilities, and validation rules.
- **`api-contract`**: OpenAPI specifications generated by the backend and TypeScript types consumed by frontends.

## 3. Dependency Graph & Rules
- Dependencies flow downwards: `apps/*` -> `packages/*` -> `external libraries`.
- Applications do not import from each other. Communication is via network using `api-contract`.
- Both `web` and `admin` applications are isolated and only share logic via `packages/ui` and `packages/shared-ts`.

## 4. CI/CD & Tooling
- **Build System**: TurboRepo caches builds and orchestrates execution.
- **Linting & Formatting**: Enforced globally using ESLint and Prettier.
- **Git Hooks**: Husky and `lint-staged` run formatting before every commit.
- **Commit Convention**: Enforced via `commitlint` to follow Conventional Commits.

## 5. Security & Workflows
- No hardcoded secrets. Environment variables handle sensitive configurations.
- AI Workflows are standardized under the `ai_prompts/` directory to provide consistent context for future agents.
