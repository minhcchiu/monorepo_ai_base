# Android Google Play Subscription Setup

## 📦 Subscription Structure

Google Play Subscription structure:

```text
Subscription
 └── Base Plan
      └── Offer (trial / discount)
```

# 🔥 Important Notes

## Product ID

* Cannot be changed later
* Used in app + backend
* Must be unique

Good examples:

```text
sub_weekly
sub_yearly
```

---

## Base Plan ID

* Cannot be changed later
* Keep short and clean

Good examples:

```text
weekly
yearly
```

---

## Trial

Do NOT put trial info inside Product ID.

❌ Wrong:

```text
sub_weekly_trial
```

✅ Correct:

```text
Product ID: sub_weekly
Offer: trial-3d
```

# 🔐 Backend Flow

```text
User Purchase
    ↓
Android Billing
    ↓
purchaseToken
    ↓
Backend Verify
    ↓
Google Play API
    ↓
ACK Purchase
    ↓
Save Database
    ↓
Unlock Premium
```

---

# ⚠️ ACKNOWLEDGE PURCHASE

Must acknowledge purchase within 3 days.

If NOT acknowledged:

* Google automatically refunds user
* Revenue lost

# 🚀 Best Practice

* Verify purchases on backend
* Never trust client only
* Save all transactions
* Store purchaseToken uniquely
* Sync subscription status periodically
* Use RTDN webhook later if scaling
